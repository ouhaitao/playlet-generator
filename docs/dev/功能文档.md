# 短剧生成平台

## 简介

agent驱动，以comfyui作为生成后端的短剧生成平台。

## 功能

### 1.0

1. agent驱动
    1. 用户输入大概的剧情、参考图等信息
    2. 通过对话的方式，agent逐步提取所需的信息，最终生成提示词
    3. 将提示词等信息调用comfyui执行工作流
2. 支持一镜到底模式与分镜模式
    1. 一镜到底：一段连贯的动画没有分镜。
    2. 分镜模式：每个分镜对应一段脚本。
3. 由于视频模型一次无法生成过长的视频，所以每一次生成的结果需要用户审核满意后再生成下一段视频。所有生成任务都执行完毕后再将视频合成一个长视频

## 技术

### 技术限制

1. 我的LLM部署环境不支持外网访问，在局域网中可以直接调用OPENAI格式的接口使用。
   为了外网也能使用，我使用deepseek harness接入的LLM，并安装了QQBOT插件，在外网可以使用QQBOT实现与LLM的对话。
   简单的说，在外网可以把QQBOT当做LLM进行对话。

### 技术选型

#### 后端

1. 使用maven管理项目
2. 使用Spring AI 2.0.2、spring boot4.1.2、JDK21构建项目
3. 音视频操作使用ffmpeg
4. 与qqbot对话使用simple robot4最新稳定版
5. 项目架构需要能够灵活拓展。
   例如LLM对话，既可以使用OPENAI风格的API，也可以使用simple robot与QQbot进行对话

#### 前端

1. 选用主流技术，由你选择
